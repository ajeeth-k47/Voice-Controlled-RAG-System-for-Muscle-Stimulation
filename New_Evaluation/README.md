# Evaluation

Human Evaluation:

Around 8 Participants were asked to evaluate the system for the 7 pre-recorded movements and 3 movements generated by them during the time of evalaution



## Run

Intructions to run Evaluation:

```bash
cd New_Evaluation
python server.py
```

Open:

- `http://localhost:8010/` -> instruction page for participants
- `http://localhost:8010/evaluate.html` -> direct evaluation page

Result page:

- `http://localhost:8010/results.html`

## Metrics shown in Results page

- Overall WBS
- WBS(Whole Body Score) per movement
- BPQ(Body part quality)
- BPQ per movement
